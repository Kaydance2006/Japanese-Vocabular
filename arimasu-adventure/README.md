# Arimasu Adventure

A beginner Japanese vocabulary game for kids, built around あります / います, particles (に が で を か) and ます verbs, using the GENKI-based class slides.

Open `index.html` in any browser. No install needed.

- 10 mini games plus a mixed "Adventure" that cycles through them
- Romaji and kanji (with furigana) can be switched on or off
- Sound effects, optional music, and Japanese voice (uses the device's built-in voice)
- Questions are generated fresh each round and recent ones are avoided
- Progress is saved in the browser only
